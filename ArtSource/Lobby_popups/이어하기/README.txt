악몽 수선소 이어하기 UI 리소스
png/ : 각 요소를 별도 파일로 분리한 실제 알파 채널 투명 PNG. 글자와 숫자는 포함하지 않았습니다.
preview.html : PNG를 조립하고 HTML 텍스트를 별도로 올린 화면 예시. 인터넷 없이 열 수 있습니다.
assembly_preview.png : 글자 없는 패널 조립 미리보기. 배경색은 미리보기 용도입니다.
asset_list.csv / assets.json : 파일명, 원본 픽셀 크기, 알파 정보.
ui_text_ko.json : 이미지와 분리된 UI 텍스트 예시. 저장 정보와 수치는 실행 중 갱신합니다.
vector/ : 드롭다운 필드 등 단순 UI 부품의 SVG 원본.

패널 그림은 원래 비율을 유지하여 사용합니다. 생성된 장식 패널에 검증되지 않은 9슬라이스 값을 지정하지 않았습니다.
버튼 기본·호버·비활성 이미지는 공통 RectTransform/컨테이너 안에 배치합니다. 호버의 빛 번짐 때문에 실제 PNG 여백이 다르므로 투명 여백을 포함한 이미지 전체 크기를 버튼 판정으로 사용하지 마세요.
누름은 기본 버튼에 런타임 tint와 0.98배 축소를 적용하는 방식입니다. 종료에는 별도 button_pressed도 포함합니다.
menu_hit_area는 거의 투명한 클릭 영역 예시입니다. 실제 엔진에서는 이미지 대신 레이캐스트 영역으로 만들 수 있습니다.
backdrop_dim은 화면 전체에 늘려 사용합니다. 문구나 저장 숫자를 PNG로 렌더링하지 마세요.
슬라이더 fill은 길이를 늘리는 대신 clipping/mask로 값 비율만 표시하고, knob는 독립 이동시킵니다.
설정의 드롭다운·키 입력창은 조립 부품이며 실제 옵션/키 충돌 검사는 게임 코드에서 처리합니다.
기존 로비 배경과 게임 로고는 이 패널 리소스팩의 범위에 포함하지 않습니다. 기존 파일을 그대로 사용하세요.
