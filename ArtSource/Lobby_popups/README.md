# 로비 팝업 이미지 (이어하기 · 새로하기 · 설정 · 종료)

로비에서 메뉴를 눌렀을 때 뜨는 창 4종의 이미지를 넣는 폴더입니다.

```
ArtSource/Lobby_popups/
  이어하기/   저장 기록 창(책 모양), 버튼
  새로하기/   새로운 이야기 확인 창, 버튼
  설정/       설정 창, 탭(사운드·화면·조작), 슬라이더, 버튼
  종료/       종료 확인 창, 버튼
```

## 원본 규칙
- 투명 배경 PNG, 원본 해상도 그대로(메신저를 거치지 않게)
- 창 틀·버튼·슬라이더는 **글자 없는 버전**이 있으면 함께 주세요. 글자는 게임에서 씁니다(번역·문구 수정이 쉬워짐).
- 버튼 상태가 있으면 `_normal`, `_hover`, `_pressed` 처럼 이름에 붙여 주세요.
- 화면 전체 시안(완성 합성본)은 `reference_*.png`로 함께 넣어 주세요. 배치 기준으로 씁니다.

## 넣는 방법
1. GitHub에서 `ArtSource/Lobby_popups` 폴더로 들어가 **Add file → Upload files**
2. Finder에서 **폴더 4개를 한꺼번에** 끌어다 놓기(폴더 구조 그대로 올라감) → **Commit changes**
3. 파일 하나가 25MB를 넘으면 실패합니다. 그때는 Mac의 `defense-game/ArtSource/Lobby_popups`에 폴더 4개를 넣고 `Setup/UploadArt.command`를 더블클릭하세요.
