# 메인(수선소) 화면 배경 레이어 (뎁스)

메인 화면 배경을 앞뒤 층으로 나눈 원본 이미지를 넣는 폴더입니다. 게임에서는 층마다 깊이를 줘서 마우스를 움직이면 살짝 시차가 생깁니다.

## 넣는 방법
GitHub 저장소에서 `ArtSource/Main_depth` 폴더로 들어가 **Add file → Upload files**에 **폴더 안의 파일들**을 끌어다 놓고 **Commit changes**를 누르세요.
(폴더째 끌어다 놓으면 `Main_depth/Main_depth/...`처럼 한 단계 더 생깁니다. 하위 폴더를 나눠 두셨다면 그대로 올려도 괜찮습니다.)

## 지금 들어 있는 파일
`KakaoTalk_Photo_...jpeg` 16장은 카카오톡으로 받아 해상도가 줄어든 임시본입니다.
원본이 올라오면 개발자가 원본으로 교체하고 임시본은 지웁니다.

## 원본 규칙
- **투명 배경 PNG** (검은 배경이면 개발자가 자동으로 지우지만, 어두운 부분이 함께 비칠 수 있습니다)
- **원본 해상도 그대로** (카카오톡·메신저를 거치지 않게 GitHub에 바로 올려 주세요)
- 파일 이름에 어떤 층인지 알 수 있으면 좋습니다(예: `01_밤하늘.png`, `05_작업대.png`). 번호가 작을수록 뒤쪽 층이면 더 좋습니다.
