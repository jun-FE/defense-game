# 전투 맵 이미지

전투 화면 맵을 넣는 폴더입니다. 카메라가 고정이라 깊이(시차) 레이어는 필요 없습니다.

## 맵 하나에 필요한 파일
맵마다 폴더를 하나 만들고(예: `ArtSource/Maps/장난감방/`) 아래 파일을 넣어 주세요.

| 파일 | 내용 |
| --- | --- |
| `base.png` | 바닥 전체 그림. 길이 그려진 맵 (필수) |
| `front.png` | 몬스터·타워보다 **앞에** 보여야 하는 것만 남긴 투명 PNG. `base.png`와 같은 크기·같은 위치 |
| `guide.png` (또는 아무 그림 위에 표시) | 몬스터가 **나오는 곳**, **꿈의 중심(도착점)**, 갈림길이 있으면 순서. 타워를 못 짓게 할 곳이 있으면 같이 표시 |
| `설명.txt` (선택) | 맵 이름, 어느 의뢰에 쓰는지 등 |

## 규칙
- 16:9 비율. 가능하면 **3840×2160**, 최소 1920×1080. 메신저를 거치지 않은 원본 PNG.
- `front.png`는 반드시 투명 배경, `base.png`와 픽셀 단위로 겹쳐야 합니다.
- 길 폭은 일정하게, 길 옆에는 타워를 놓을 빈 바닥(풀밭·마루)을 남겨 주세요. 병정인형은 길 바로 옆 칸에 놓입니다.
- 랜턴처럼 빛나는 물건은 그대로 그려 두면 게임에서 위치를 찍어 일렁이는 빛을 더합니다.
- 길과 설치 칸은 그림을 받은 뒤 개발 쪽에서 데이터로 맞춥니다.

## 넣는 방법
파일이 25MB 이하면 GitHub 웹 업로드(**Add file → Upload files**), 크면 Mac의 `defense-game/ArtSource/Maps`에 넣고 `Setup/UploadArt.command`를 더블클릭하세요.
