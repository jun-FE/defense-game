# 로비(첫 화면) 이미지

게임을 켜면 처음 보이는 화면(게임 시작, 이어하기, 설정, 종료 등)에 쓰는 이미지를 넣는 폴더입니다.
배경을 층(뎁스)으로 나눴다면 층별 파일을 모두 넣어 주세요. 메인(수선소) 화면처럼 마우스 시차를 줍니다.

## 넣는 방법
GitHub 저장소에서 `ArtSource/Lobby_depth` 폴더로 들어가 **Add file → Upload files**에 **폴더 안의 파일들**을 끌어다 놓고 **Commit changes**를 누르세요.

## 원본 규칙
- **투명 배경 PNG**, **원본 해상도 그대로** (메신저를 거치지 않게)
- 화면 시안(완성 합성본)이 있으면 `reference` 이름을 붙여 함께 올려 주세요(예: `reference_lobby.png`). 배치 기준으로 씁니다.
- 버튼(게임 시작, 이어하기 등)을 이미지로 만들었다면 글자 없는 버전과 상태별 파일(`_normal`, `_pressed`, `_disabled`)로 주세요.
- 파일 이름에 층 순서를 알 수 있으면 좋습니다(예: `01_하늘.png`, `02_건물.png`).
