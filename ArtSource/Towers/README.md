# 타워 이미지

전투 화면의 타워 그림을 넣는 폴더입니다. 기본 타워(드림캐처) 원본 `dreamcatcher_sheet.jpg`도 여기에 있습니다.

## 넣는 방법
1. GitHub 저장소에서 `ArtSource/Towers` 폴더로 들어갑니다.
2. **Add file → Upload files**를 누릅니다.
3. **타워별 폴더째로** 끌어다 놓습니다. 폴더 구조가 그대로 올라갑니다.
4. **Commit changes**를 누릅니다.

```
ArtSource/Towers/
  드림캐처/   ← 타워 이름(한글이어도 됨)
  랜턴/
  ...
```

## 원본 규칙
- **투명 배경 PNG**, **원본 해상도 그대로**. 메신저를 거치면 압축되니 피해 주세요.
- 한 타워의 모든 프레임은 **같은 캔버스 크기**로, 타워 발밑(땅에 닿는 점)이 같은 위치에 오게 해 주세요.
- 상태별로 이름을 붙여 주세요. 숫자는 프레임 순서입니다.
  - `idle_01.png, idle_02.png …` 대기
  - `attack_01.png …` 공격
  - `build_01.png …` 설치(있으면)
  - `upgrade_1.png, upgrade_2.png` 강화 단계별 모습(있으면)
- 투사체·이펙트는 `projectile_…`, `effect_…`, 건설 버튼·도감용 아이콘은 `icon.png`로 주세요.
- 한 장에 여러 프레임을 모은 시트도 괜찮습니다. 그때는 칸 수와 순서를 알려 주세요.
- 타워 설명(이름, 공격 방식, 공격속도 등)이 있으면 `설명.txt`로 같이 넣어 주세요.
